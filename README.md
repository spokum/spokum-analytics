# СпокУм Аналитика

Дашборд статистики социальной сети СпокУм.

## Функции

- Пароль для доступа (3456)
- Статистика пользователей, постов, подарков, сообщений, монет
- Онлайн сейчас и за 24 часа
- Активность за неделю с графиком
- Распределение настроений
- TikTok статистика @spokum2 (редактируемая)
- Красивая сводка за месяц с экспортом в PNG

## Технологии

- Next.js 16
- TypeScript
- Tailwind CSS
- Recharts
- Supabase (данные СпокУма)
- html-to-image (экспорт сводки)

## Запуск

```bash
bun install
bun run dev
```

Открой http://localhost:3000, введи пароль 3456.
